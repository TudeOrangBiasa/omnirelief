# Monorepo Better-T-Stack

Scaffold awal `create-next-app` diganti monorepo Better-T-Stack karena butuh struktur baku untuk reproducible build plus deploy Vercel per service. Konsekuensinya ada paket `turborepo` dan `drizzle` bawaan yang ikut, dan env wajib didaftarkan di `turbo.json` kalau tidak build buta.
