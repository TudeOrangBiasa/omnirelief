# Perubahan

Semua perubahan penting dicatat di sini. Bahasa Indonesia. Satu baris per perubahan.

## Aturan versi

Versi mengikuti semver pada seri 0.x. Patch naik untuk perbaikan bug. Minor naik untuk fitur baru. Angka mayor tetap 0 sampai API dan skema stabil untuk publik.

Versi ditahan di `0.1.x` sampai kode matang. Tanpa tag dan tanpa GitHub release selama masa tahan. Perubahan menumpuk di seksi Unreleased di bawah.
